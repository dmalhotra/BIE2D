# BIE2D

BIE2D is a header-only C++ library, built on [SCTL](https://github.com/dmalhotra/SCTL), for boundary integral equations in two dimensions on many close-to-touching discs: the Laplace capacitance and elastance problems and the Stokes mobility problem. It includes drivers for the sedimentation of discs in Stokes flow.
